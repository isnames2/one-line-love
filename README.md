# One Line to Make the Judge Fall in Love

One line, at most 240 characters, to make the judge fall in love with a person. The program writes that line to `/output/entry.txt`.

## The line

> She still saves the burnt corner of the toast for herself, because the part nobody else wants is the part she loves most — and that is how I learned to love her.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Standard library only; running it twice produces byte-identical output.
